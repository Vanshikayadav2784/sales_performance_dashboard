# 📊 Category Performance Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing category-wise business performance using Power BI. The dashboard was created using a CSV-based retail sales dataset to evaluate key metrics such as revenue, profit, order volume, and regional sales trends.

## 🎯 Objective
To build an interactive Power BI dashboard that helps understand:
- 📦 Category-wise sales performance
- 💰 Revenue and profit contribution
- 🌍 Region-wise performance
- 📈 Monthly sales trends
- 🏆 Top-performing business segments

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- CSV Dataset
- Data Visualization
- KPI Reporting

## ✨ Dashboard Features
- 💰 KPI Cards for Total Revenue, Total Profit, and Total Orders
- 📦 Category-wise Performance Analysis
- 🌍 Region-wise Sales Analysis
- 📈 Monthly Sales Trend with Drill-down by Year/Quarter/Month
- 🎛️ Interactive Slicers for Region, Category, and Order Date
- 🔄 Cross-filtering between visuals for dynamic exploration
- 🖱️ Hover Tooltips for quick metric insights
- 🔍 Drill-down and filter-based analysis for category-level reporting

## 📊 Key Insights
- 🏆 Identified high-performing categories based on revenue and profit contribution
- 🌍 Compared regional sales performance to highlight growth opportunities
- 📈 Analyzed monthly trends to understand sales fluctuations over time
- 🎯 Used interactive filters to improve category-level business analysis
